====================================================
  POSTMAN TESTS - ADMIN CRUD (Rooms, Packages, Activities)
  Base URL: http://127.0.0.1:8000
====================================================

IMPORTANT AVANT DE COMMENCER:
- Tu dois être connecté en tant qu'admin.
- Dans Postman, active "Manage Cookies" pour garder la session.
- Ajoute dans chaque requête POST/PUT/DELETE le header:
    Accept: application/json
- Pour les requêtes POST/PUT, utilise Body > form-data.

====================================================
  STEP 0 — LOGIN (obligatoire avant tout)
====================================================

POST http://127.0.0.1:8000/login
Body (form-data):
  email    = admin@example.com
  password = password

=> Résultat attendu: redirection 302 vers /admin/dashboard


====================================================
  1. ROOMS
====================================================

--- INDEX ---
GET http://127.0.0.1:8000/admin/rooms
=> Résultat attendu: 200 OK — liste des chambres

--- CREATE FORM ---
GET http://127.0.0.1:8000/admin/rooms/create
=> Résultat attendu: 200 OK — formulaire de création

--- STORE (créer une chambre) ---

====================================================
  COMMENT RÉCUPÉRER LE CSRF TOKEN DANS POSTMAN
====================================================

Option 1 (recommandée):
  - Fais d'abord GET http://127.0.0.1:8000/admin/rooms/create
  - Dans l'onglet "Cookies", copie la valeur de "XSRF-TOKEN"
  - Postman l'envoie automatiquement si tu actives:
    Settings > "Automatically follow redirects" = ON
    Settings > "Send cookies" = ON

Option 2:
  - Ajoute ce header sur toutes tes requêtes:
    X-XSRF-TOKEN: {{XSRF-TOKEN}} (depuis le cookie)
